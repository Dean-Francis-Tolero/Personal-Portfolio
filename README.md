# deanfrancistolero.com

A digital playground. Part portfolio, part creative outlet, part documentation of the journey.
Not just a place to list projects. A place to think out loud, experiment with ideas, and put
things on the internet that are actually mine.

---

## About Me

Dean Francis Tolero. CS grad, Magna Cum Laude, Canadian University Dubai (GPA 3.81/4.0).
I started programming at 16 and haven't really stopped since.

I work mostly in AI and software engineering. Currently co-authoring research on Agentic AI,
previously building websites, automation tools, and systems that ended up being used by real people.
One of those was an RFID attendance system I sold to a school. Another was a federated learning
phishing detector I built for my graduation project. I like making things that actually do something.

When I'm not building, I'm reading, thinking, or writing about what I learned.

---

## The Site

Built as a personal project to have a home on the internet that reflects how I actually think.
The design is intentionally minimal: monochrome, one typeface, no unnecessary decoration.
The writing is honest. The projects are real.

---

## Stack

- Next.js 16 + TypeScript
- Tailwind CSS v4
- Framer Motion + GSAP + Lenis
- Deployed on Vercel

---

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
